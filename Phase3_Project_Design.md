# Phase 3: Project Design

## System Architecture (Data Flow)

```
[Excel Spreadsheet]
        |
        v
[Import Set Table: u_employee_import]  <-- staging area
        |
        v   (Transform Map: Sample Spreadsheet Import)
        |
        v
[Target Table: u_employee_test]  <-- final clean data
        |
        v
[Reports: Pie / Bar / List]
        |
        v
[Employee Analytics Dashboard]
```

## Table Design

### Target Table: Employee Test (u_employee_test)
| Column Label | Field Name | Type |
|---|---|---|
| Employee ID | u_employee_id | String |
| Employee Name | u_employee_name | String |
| Email | u_email | String |
| Department | u_department | String |
| Location | u_location | String |

### Staging Table: Employee Import (u_employee_import)
Auto-generated by ServiceNow's Load Data wizard based on the uploaded spreadsheet's columns.

## Transform Map Design
- **Name:** Sample Spreadsheet Import
- **Source Table:** Employee Import (u_employee_import)
- **Target Table:** Employee Test (u_employee_test)
- **Field Mapping:**

| Source Field | Target Field | Coalesce |
|---|---|---|
| u_name | u_employee_name | false |
| u_employee_id | u_employee_id | **true** |
| u_department | u_department | false |
| u_location | u_location | false |
| u_email | u_email | false |

Coalesce is enabled only on **Employee ID** since it is the unique key that identifies
whether an incoming record is new or an update to an existing one.

## Report Design
| Report | Type | Group By | Aggregation |
|---|---|---|---|
| Employees by Department | Pie Chart | Department | Count |
| Employees by Location | Bar Chart | Location | Count |
| Employee List Report | List | (columns: ID, Name, Email, Dept, Location) | N/A |

## Dashboard Design
- **Name:** Employee Analytics Dashboard
- **Widgets:** All 3 reports above, arranged side-by-side
- **Access:** Restricted via Share option (Users/Groups/Roles) as needed
