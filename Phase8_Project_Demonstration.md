# Phase 8: Project Demonstration

## Demo Video Checklist
The demo video (screen recording + voice-over) should cover, in order:

1. **Project Name**
   - "Import Data using Transform Maps (Spreadsheet)" — ServiceNow micro-project

2. **Purpose of the Project**
   - Explain the real-world problem: bulk employee data often arrives in Excel and
     needs to be migrated into ServiceNow accurately and without duplicates

3. **Use / Benefits of the Project**
   - Saves manual data entry time
   - Ensures data accuracy via structured field mapping
   - Prevents duplicate records automatically via Coalesce
   - Gives instant visual insight via Reports & Dashboard

4. **Project Execution / Working Process** (show live on screen)
   - Show the source spreadsheet
   - Show the Employee Test table creation
   - Show the Import Set + Transform Map setup
   - Run the Transform and show the success message
   - Show the Employee Test table populated with data
   - Show enabling Coalesce, then re-uploading modified data (updates + inserts)
   - Show re-uploading identical data (all ignored — proving no duplicates)
   - Show the 3 Reports (Pie, Bar, List)
   - Show the final Dashboard with all 3 reports together

5. **Final Output**
   - The completed Employee Analytics Dashboard showing live employee data
     grouped by Department and Location, plus the full employee list
