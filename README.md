# Import Data using Transform Maps (Spreadsheet)

A ServiceNow micro-project demonstrating end-to-end data migration from an Excel
spreadsheet into ServiceNow using Import Sets and Transform Maps, with duplicate
prevention (Coalesce) and business analytics (Reports + Dashboard).
